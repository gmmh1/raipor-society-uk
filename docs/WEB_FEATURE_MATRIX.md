# Web Feature Matrix

## Public Website

- Home
- About
- Programs
- Events listing (live, API-backed)
- Blog / News listing and post detail
- Shop (browse, cart, checkout — with product images and size selection)
- Donate
- Contact

## Member Portal

- Dashboard
- Membership status and renewal
- Events registration and history
- Shop orders and receipts
- Documents and policy access
- Voting and polling
- Notification center
- Chat (direct and group channels)
- Family / guardian consent
- AI assistant access

## Admin Portal

- Operations dashboard
- Membership administration
- Events administration (create, publish, cancel)
- Blog / News administration (write, publish/unpublish, delete)
- Shop administration (products, orders, anonymous donations)
- Finance administration
- Governance and election management
- Documents administration
- Audit and analytics views

## Non-functional requirements

- Role-based authorization
- Accessibility and responsive layout
- Security headers and middleware
- GDPR-aware data handling
- Cloudflare edge protections
- Vercel preview and production deployments
